## 踩坑记录（本次会话两个大坑）

1. **conda 装 PG 路线放弃**：conda 23.7.4 只有经典求解器，解不动新版 conda-forge
   的 vc/openssl 联合依赖约束，反复 UnsatisfiableError——不如直接换 Docker
2. **PG 连接绝不能注册成 DataSource Bean**：容器里一旦有自定义 DataSource，
   Spring Boot 的 DataSourceAutoConfiguration 就退让、MySQL 主数据源不创建，
   MyBatis-Plus 抓到 PG 连接查业务表报 relation "power_station" does not exist。
   解法：Hikari 池在 pgJdbcTemplate Bean 方法内部构建，不暴露给容器
   （详见 PgVectorConfig 注释）
3. **@ConfigurationProperties 直接绑 HikariDataSource 绑不上 url**：
   yml 的 url 键对不上 Hikari 的 setJdbcUrl setter，需先绑到 POJO 再 DataSourceBuilder 构建
