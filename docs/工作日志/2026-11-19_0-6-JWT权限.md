## 任务名称

0-6 JWT 权限：三角色（管理员 / 电站负责人 / 运营）登录鉴权

## 基础目标

1. `sys_user` 表 + 3 个种子用户（admin / manager / operator）
2. 登录接口：BCrypt 密码校验 → 签发 JWT
3. 认证拦截器：解析 token → ThreadLocal 用户上下文
4. 角色鉴权：自定义 `@RequireRole` 注解，写接口按角色控制
5. 为阶段 3 Agent "我的工单"身份绑定铺路

## 设计

- **数据模型**：`sys_user(username 唯一, password 存 BCrypt 哈希, role, station_id 可空——电站负责人绑电站用)`
- **登录链路**：`POST /api/auth/login` → BCrypt 校验 → JWT 签发（subject=userId，claims 带 username/role/stationId，24h 过期）
- **认证**：`LoginInterceptor` 解析 `Authorization: Bearer <token>` → `UserContext`(ThreadLocal)；失败 40100
- **授权**：`@RequireRole` 注解（方法级优先于类级）+ `RoleInterceptor` 校验；失败 40300
- **保护策略**：`/api/**` 默认全部要求登录，仅 `/api/auth/login` 白名单（安全默认值）；角色注解只加在写操作上
- **演示点**：station 写接口仅 ADMIN；order 创建仅 OPERATOR、接单/完工仅 MANAGER
- **设计决策**：认证与授权分两个拦截器（职责分离）；错误码沿用 0-2 预留的 40100/40300；拦截器后置 `UserContext.clear()` 防线程池复用串号（真实生产事故）；角色枚举放 common/security（biz→common 依赖方向约束）

## 所用技术

- jjwt 0.12.6（`Jwts.builder()/parser().verifyWith()` 新 API，pom 0-4 时已备）
- Hutool `BCrypt`（密码加盐哈希，无需引 Spring Security）
- Spring MVC `HandlerInterceptor` + `WebMvcConfigurer` 注册
- ThreadLocal 用户上下文、自定义注解 `@RequireRole`
