# 月度计划考核规则

> 适用范围：平台内全部并网运行电站。本文档对应系统"考核跑批"功能（凌晨 1 点定时执行）。

## 1. 考核对象与周期

- 考核对象：所有状态为"并网运行"的电站。
- 考核周期：自然月。每天凌晨 1 点执行一次跑批，对本月至今的完成情况进行滚动评估。
- 考核窗口：本月 1 日至昨天。今天的数据尚未生成，不纳入评估。

## 2. 时间进度

时间进度表示本月已流逝时间占整月的比例，计算方式：

```
时间进度 = 昨天是本月第几天 ÷ 本月总天数
```

示例：11 月 20 日跑批时，昨天是 19 日，时间进度 = 19 ÷ 30 = 63.3%。

## 3. 发电进度

发电进度表示电站本月累计实际发电量占月计划电量的比例：

```
发电进度 = 本月累计实际发电量 ÷ 月计划电量
```

- 月计划电量由电站装机容量、月度发电系数测算，写入每日统计记录。
- 本月累计实际发电量为月初至昨天全部日发电量之和。

## 4. 判定规则

- 判定公式：发电进度 < 时间进度 × 0.9 → 判定为"欠进度"（BEHIND），否则为"正常"（NORMAL）。
- 0.9 为欠进度判定系数：允许发电进度落后时间进度 10% 的缓冲，避免轻微波动误报。
- 月初豁免：每月前 3 天不执行考核。月初时间进度接近 0，按公式会把所有电站误判为欠进度。
- 欠进度状态是滚动评估：电站补足发电量后，次日跑批自动恢复为"正常"。

## 5. 欠进度告警

- 告警触发条件：电站状态由"正常/首次评估"变为"欠进度"时发送告警消息。
- 幂等机制：连续多日欠进度只告警一次，避免运营人员每天被同一电站刷屏；恢复后再欠进度才会重新告警。
- 告警通道：RabbitMQ 消息队列，内容包含电站编号与考核月份。

## 6. 结果存储与查询

- 考核结果存储在月度考核表中，按"电站 + 考核月份"唯一，每天跑批覆盖更新。
- 管理台"考核结果"页可按月份查询全部电站的：月计划电量、累计发电量、时间进度、发电进度、考核状态、考核时间。
- 结果按发电进度降序排列，欠进度电站排在最前。
