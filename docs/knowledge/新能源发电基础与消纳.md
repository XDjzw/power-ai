# 新能源发电基础与消纳

> 适用范围：风电、光伏发电原理基础知识与限电/弃风弃光问题的政策背景。
> 本文档是《限电与弃风》的背景知识篇：前者定义平台内的限电指标口径，本文解释限电为何产生、国家如何治理。

## 1. 风力发电原理

- 能量来源：单位时间内流过风轮扫掠面积的气流动能为 E = ½ρSv³（ρ 空气密度，S 扫掠面积，v 风速），功率与风速三次方成正比——风速是发电量最敏感的变量。
- 贝茨极限：德国物理学家贝茨（Betz）于 1919 年证明，风力机最多只能提取流经风轮横断面风能的 **59.3%**（16/27）。当风轮后方风速降至来流风速的 1/3 时达到该理论最大值。
- 实际风能利用系数 Cp 一般为 0.15~0.5，高性能机组约 0.45；实际值受空气动力、机械、电气损耗制约，永远低于贝茨极限。
- 机型：双馈异步机组（齿轮箱增速 + 变流器）与直驱永磁机组（无齿轮箱、低转速大直径发电机）是两大主流路线，直驱路线免去齿轮箱这一高故障部件。

## 2. 光伏发电原理

- 光伏效应：半导体 PN 结吸收光子（光子能量大于硅的带隙 1.12eV）激发电子-空穴对，内建电场将其分离，形成光生电压；接上负载即输出直流电。该效应 1839 年由法国物理学家贝克勒尔发现。
- 组件类型：主流为晶硅组件（单晶硅转换效率高于多晶硅），另有碲化镉、铜铟镓硒（CIGS）等薄膜组件。
- 光伏电站直流侧经逆变器转为交流并网，因此逆变器是光伏电站并网的关键设备。

## 3. 弃风弃光问题的成因与历史

限电的直接成因是电网消纳能力不足：

- 送出通道受限：风电大发时段本地消纳不足、外送线路容量饱和，调度要求压出力。
- 调峰能力不足：以燃煤为主的电源结构中可调节容量有限；北方冬季供热机组"以热定电"无法调峰，新能源出力空间被压缩。
- 省间壁垒：跨省跨区输送通道和交易机制不畅，富余电量送不出去。

历史数据（据公开统计）：2016 年一季度全国平均弃风率 26%，"三北"地区逼近 40%（吉林 53%、新疆 49%、甘肃 48%）；2017 年弃风率约 12%、弃光率约 6%，2018 年进一步降至弃风率约 7%、弃光率约 3%，但新疆、甘肃、内蒙古仍占全国弃风弃光总量的 90% 以上。

## 4. 可再生能源电力消纳保障机制

国家发改委、国家能源局印发《关于建立健全可再生能源电力消纳保障机制的通知》（发改能源〔2019〕807 号），对各省设定可再生能源电力消纳责任权重，核心是"一项保障目标，两种指标类型，两类义务主体"：

- 两种指标：总量消纳责任权重、非水电消纳责任权重；各设最低权重与鼓励性权重。
- 两类义务主体：直接向用户供/售电的电网企业、独立售电公司等按年售电量承担；通过电力批发市场购电的电力用户和自备电厂企业按年用电量承担。
- 完成方式：就地消纳、跨区输送消纳，配合超额消纳量交易与绿证自愿认购等市场化方式。

消纳能力的主要瓶颈（刘吉臻院士团队归纳）：功率平衡、功率调节性能、输电容量、负荷水平。

## 5. 与平台的关系

- 平台日统计的"限电损失电量 / 限电比例"口径见《限电与弃风》文档；本文的政策背景用于解释"为什么冬季光伏考核会欠进度""为什么 WF003 冬季限电比例高"等现象。
- 消纳责任权重是新能源项目投资与考核压力的政策根源，也是运营平台监控限电指标的行业背景。
