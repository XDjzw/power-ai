# 设备故障与工单管理

> 适用范围：设备故障术语与工单流转规则。本文档对应平台"工单管理"功能。

## 1. 故障类型术语

| 故障类型 | 说明 | 典型设备 |
|---|---|---|
| 变桨系统 | 风机叶片桨距角调节机构故障，导致叶片无法随风速调节受风角度 | 变桨电机、变桨齿轮箱、滑环 |
| 齿轮箱 | 风机主传动齿轮箱故障，如齿面点蚀、轴承过热、油温异常 | 主齿轮箱、高速轴轴承 |
| 逆变器 | 光伏电站直流转交流设备故障，导致组串无法并网 | 集中式逆变器、组串式逆变器 |
| 集电线路 | 汇集多台机组电能的线路故障，如跳闸、电缆绝缘损坏 | 集电线路、箱变 |

齿轮箱故障是风电场停机时长最长的故障类型，单次维修常需吊装更换，应优先响应。

## 2. 工单状态机

工单按固定状态机流转，不允许任意跳转：

```
WAITING（待接单）→ PROCESSING（处理中）→ DONE（已完成）
                         ↓ 超时未完工
                      TIMEOUT（已超时）→ ESCALATED（已升级）
```

- 待接单：运营人员创建工单后的初始状态，等待电站负责人接单。
- 处理中：电站负责人接单并登记处理人后进入。
- 已完成：负责人完工登记后进入，工单归档。
- 已超时：工单超过时限未完工，由系统自动升级，无需人工操作。
- 已升级：超时工单进一步上报后的状态，代表需要更高层级介入。

## 3. 角色与权限

- 运营专员：创建工单、跟踪进度。工单由运营侧发起。
- 电站负责人：接单、登记处理人、完工登记。负责人只能处理本电站的工单动作。
- 管理员：维护电站台账等主数据，不直接参与工单流转。
- 工单是审计数据：不提供修改与删除接口，流转全程留痕。

## 4. 超时升级机制

- 工单创建后进入消息队列计时，超过时限（生产环境 2 小时）自动触发超时检查。
- 超时检查时工单仍未完工的，状态自动流转为"已超时"并升级。
- 超时升级是可靠性设计的一部分：即使系统无人值守，工单也不会永远停在"处理中"。
