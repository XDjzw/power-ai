# 设备结构与故障处置

> 适用范围：风电场、光伏电站主要设备构成、常见故障模式与规程性处置要求。
> 本文档与《设备故障与工单管理》配套：前者定义平台内的故障类型术语，本文给出设备结构与处置依据。
> 处置要求部分整理自《防止电力生产事故的二十五项重点要求（2023版）》（国能发安全〔2023〕22号）。

## 1. 风电机组基本结构

并网风电领域主要采用水平轴风电机组，基本结构如下：

| 部件 | 功能 |
|---|---|
| 风轮 | 叶片 + 轮毂，捕获风能并转化为旋转机械能 |
| 传动系统 | 主轴、齿轮箱、联轴器；齿轮箱将风轮低速旋转增速至发电机所需转速（双馈机型） |
| 发电机 | 双馈异步发电机（带齿轮箱增速）或直驱永磁同步发电机（无齿轮箱、低转速大直径） |
| 变桨系统 | 调节叶片桨距角，控制捕获风能大小，也是气动刹车手段 |
| 偏航系统 | 根据风向转动整个机舱，使风轮始终正对来风 |
| 机舱 / 塔架 / 基础 | 承载与防护结构 |

## 2. 光伏电站主要设备

光伏电站系统主要由光伏组件、支架、直流线缆、逆变器、汇流箱、箱变、升压站设备等组成。
运维统计显示：组件、逆变器、汇流箱等**直流侧设备故障占比约 90%**，交流侧（电缆、箱变、升压站）仅约 10%；
其中**逆变器故障次数占比最高（约 60%）**，组件故障类型最杂。

## 3. 风电机组常见故障模式

行业普遍采用 FMEA（故障模式及影响分析）法对风电机组故障分类，主要集中于变频器、发电机、齿轮箱、变桨系统、偏航系统、叶片和制动系统：

| 子系统 | 典型故障模式 |
|---|---|
| 齿轮箱 | 箱体失效、齿轮传动系统故障、润滑与冷却系统故障、支撑系统故障、传感器故障 |
| 变桨系统 | 变桨轴承 / 齿轮箱 / 电机 / 驱动器失效、后备电源与充电器失效、编码器与限位开关失效、控制模块故障 |
| 偏航系统 | 偏航轴承 / 齿轮箱 / 电机 / 传感器故障、偏航刹车系统故障 |

齿轮箱是风电场停机时长最长的故障类型，单次维修常需吊装更换（与工单管理文档呼应）。

## 4. 光伏组件与逆变器常见故障

- **热斑**：局部电池片被遮挡后不再发电而成为负载，被遮盖部分升温远超其他部分形成烧坏的暗斑；严重时焊点熔化、毁坏栅线，使组件实际寿命至少减少 10%。遮挡（积尘、鸟粪）与组件自身质量是两大成因。
- **隐裂**：电池片内细小裂纹，肉眼难辨；加速功率衰减，机械载荷下扩大，可诱发热斑，发展为碎片。多由运输、施工等外力造成。
- **蜗牛纹**：裂纹 + 水分渗透 + 阳光照射三者共同作用，银离子与封装材料反应沿裂纹生成氧化银/硫化银，呈黑色或白色线状图案。
- **PID（电位诱导衰减）**：组件长期高电压对地运行导致功率衰减。
- **逆变器**：通讯故障、IGBT 故障、过温、电网电压/频率超限误报、残余电流检测装置故障等；逆变器单台故障影响整条组串并网，故障影响重大。

## 5. 规程性处置要求（二十五项反措 2023 版要点）

防止风力发电机组着火事故（第 2.11 条）：

- 机舱、塔筒内一次设备动力电缆必须选用阻燃电缆，电缆孔洞用耐火极限不低于 1h 的不燃材料封堵。
- 严格监控轴承、发电机、齿轮箱及机舱内环境温度：发电机轴承温度报警值不超过 85℃，停机温度不超过 95℃。
- 每季度检查防雷接地回路，每年测量防雷系统接地电阻，单机工频接地电阻应不大于 4Ω。
- 齿轮油及液压油系统应严密无渗漏，采用不易燃烧或闪点高于机组运行最高温度的油品。
- 机舱内配置自动消防系统（探测器、火灾报警装置、灭火装置），严禁存放易燃物品。

防止风电机组、光伏逆变器大面积脱网事故（第 5.2 条）：

- 风电场应配置安全稳定控制装置；光伏发电站应有防"三误"（误接线、误碰、误整定）措施。
- 对可能存在次同步振荡、超同步振荡风险的风电场和光伏发电站，应在投运前开展风险研究并采取抑制、保护和监测措施。

高处作业安全：塔筒清洗、叶片维修等高处作业必须在风机停机状态并将叶轮锁定后进行，作业人员使用独立安全绳、防坠器。
