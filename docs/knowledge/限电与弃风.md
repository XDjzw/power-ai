# 限电与弃风

> 适用范围：风电、光伏电站的发电损失分析。本文档对应平台日统计中的限电指标。

## 1. 基本定义

- 弃风：风力发电场因电网消纳能力不足、送出通道受限等原因，被迫放弃的可发电量，是风电领域最主要的非计划损失。
- 限电：电网调度机构对电站下达出力限制指令，电站按指令降低发电功率。限电造成的损失电量称为限电损失电量。
- 弃光：光伏电站的同类损失，成因与弃风一致。

## 2. 指标口径

平台日统计中涉及两个限电指标：

- 限电损失电量（kWh）：当日因限电未能发出的电量，由电站理论可发电量与限电后实际发电量之差计算。
- 限电比例：限电损失电量占理论可发电量的比例，计算公式：

```
限电比例 = 限电损失电量 ÷ (实际发电量 + 限电损失电量)
```

## 3. 典型成因

- 送出通道受限：风电大发时段（大风天）本地消纳不足、外送线路容量饱和，调度要求压出力。
- 冬季供暖期：北方冬季以保供热机组运行为主，新能源出力空间被压缩，是限电高发季节。
- 光伏电站冬季日照弱、发电量低，但相同限电小时数对月度发电进度的影响占比更大，容易触发月度考核欠进度。

## 4. 平台内的典型现象

- 北疆风电场（WF003）冬季限电比例长期处于 8%~25% 区间，是"季节性限电"的代表案例。
- 光伏电站在冬季普遍发电进度落后于时间进度，属正常季节规律，考核时应结合限电比例综合判断，而非直接认定管理责任。
