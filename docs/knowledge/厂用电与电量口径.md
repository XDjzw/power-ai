# 厂用电与电量口径

> 适用范围：电站日统计数据的指标解释。本文档对应平台日统计中的四类电量与厂用电率。

## 1. 四类电量口径

电站每日统计包含四类电量，口径如下：

- 日发电量（kWh）：电站当日全部机组实际发出的电量，是考核与发电效率分析的基础指标。
- 日上网电量（kWh）：电站向电网输送、被电网计量的电量，是电站的收入口径。
- 日厂供电量（kWh）：电站向站内生产设备提供的电量。
- 日厂用电量（kWh）：电站内部照明、监控、变流器散热、油泵等辅助设备消耗的电量。

四者关系：发电量 = 上网电量 + 厂供电量 + 厂用电量 + 各类损耗（含限电损失）。上网电量是发电量中真正产生收益的部分。

## 2. 综合厂用电率

综合厂用电率反映电站自身耗电水平，是运营效率的核心指标：

```
综合厂用电率 = 厂用电量 ÷ 日发电量
```

- 风电场正常水平约 1%~3%；光伏电站约 1%~2%（无变桨液压、齿轮箱润滑等机械耗电设备，厂用电率通常更低）。
- 厂用电率异常升高可能意味着：设备老化、散热系统故障、变流器效率下降，应结合故障工单排查。
- 限电期间发电量被压缩而厂用电基本不变，会出现厂用电率"被动升高"的假象，分析时需剔除限电影响。

## 3. 利用小时数

利用小时数是衡量机组发电效率的另一指标：

```
利用小时数 = 日发电量 ÷ 装机容量
```

- 年利用小时数：风电行业通常为 1800~2500 小时，光伏为 1000~1600 小时，地域差异显著。
- 利用小时数低于区域平均水平，是"欠进度考核"之外判断电站健康度的辅助依据。
